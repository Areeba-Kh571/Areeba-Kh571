## 🔭 Featured work

### 🧠 AIDEN — AI-Powered Dementia Early Navigator
Alzheimer's detection using speech features (DementiaBank/Pitt) and cognitive features (ADNI).
- Found and fixed **data leakage** from CDR-derived features, then re-evaluated honestly
- **GroupKFold** by speaker to prevent identity leakage in speech models
- **SHAP** explanations for both modalities
- Cognitive model: 81.1% accuracy, 0.908 AUC · Speech model: 77.9% accuracy, 0.869 AUC
- Regulatory framing as SaMD with ISO 13485 / IEC 62304-style documentation

### 📈 Applied Search Intelligence — FlyRank Capstone
Ranked declining web pages for content refresh using Google Search performance data.
- Compared a hand-written rule against Decision Trees and Random Forest (Precision@50)
- Key finding: the complex model won on development data, but the **simple rule generalized better to unseen clients**, a real lesson in overfitting and group-wise validation
